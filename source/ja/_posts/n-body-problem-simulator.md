## 実装

### 可視要素

#### 星（"S"）

N体問題では、まずN個の星、つまりSで表されるN個の点が必要です。具体的な数はカスタマイズの原則に従い、ユーザー自身が調整できるようにします。
まず、ユーザーが入力した星の数を保持する変数 $n$ を作成し、同時に $N_{um}=[1,2,\dots,n]$ というリストを入力しておきます。このときDesmosが自動で等差数列を補完します。

{% callout type="warning" title="変数の定義域に注意" icon="fa-solid fa-triangle-exclamation" %}
すべての要素に定義域（範囲、スライダーのステップ幅など）を設定し、数学的な誤りを避けるよう注意してください。
例：

$$
n=15
$$

$$
{2}\le{n}\le{100}~ステップ:1
$$

~~まともな人間が星を-1個なんて設定するわけないですよね~~

注：Desmosはリスト長の上限が10000項目のため、星の数は100個を超えてはいけません。そうでなければ作用リストの項目数 $n^2$ が10000項目を超えてしまいます（この点は後述します）。~~100に設定して本当に重くならないのか~~
{% endcallout %}

ここでの星は点群として当然座標を設定する必要があります。

**タスク1：Sを表す適切な方法を見つける**

筆者がここを書いているときに思いついた案は以下のとおりです：

{% tabs %}

<!-- tab 案一 -->

$S=[(1,2),(3,4),...]$ とすればよいとすぐに思いつきますが、各項を個別に設定するのは現実的ではないため、案一はpass。

<!-- tab 案二 -->

以上の問題を解決するには、 $S$ に一括でランダムな値を代入する必要があるため、関数 $random()$ とリスト内包表記 $for$ を導入します。~~これってpyではループって言うんじゃなかったっけ~~

{% folding title="Desmos関数random()の使い方入門" class="blue" open=true %}
なに、使い方を聞くんですか？文字どおり、randomは乱数です。ただし、いくつか注意すべき細かい点があります：
1. $random()$ 関数を書くときは必ず括弧を付けます（中に何もなくても）。
2.その関数の括弧の中に自然数（ $x$ とする）を書くと、x個の異なる乱数を含むリストを生成できます。
3.その関数が生成する乱数の範囲は $[0,1]$ で、変更できません（これで既にチューリング完全だからです）。調整したい場合は、以下の書き方を参考にしてください：
$ランダム数の範囲を[a,b]({a,b}\in{\mathbb{R}})とすると、r=a+random()(b-a)$ 。
{% endfolding %}

{% folding title="Desmosリスト内包表記forの使い方入門" class="blue" open=true %}
$for$ を利用すると、リスト内のすべての要素を走査して1つずつ計算に代入できます。例えば $sin(i)~for~i=[1,2,\dots,10]$ と入力すると、以下が出力されます：
=`0.0174524064373` `0.0348994967025` `0.0523359562429` `0.0697564737441` `0.0871557427477` `0.104528463268` `0.121869343405` `0.13917310096` `0.15643446504` `0.173648177667`
ループする変数が2つあれば「二重ループ」の効果が得られます（ループの中にもう1つループを入れ子にするのと同じです。変数がさらに増える場合も同様です）：
$(a,b)\space{for}\space{a}=[1,2,\dots,10],b=[1,2,\dots,10]$
上の例は ${10}\times{10}=100$ 個の点を含むリストを出力します。
{% endfolding %}

以上の内容に基づき $S=(a,b)~for~a=random(n),b=random(n)$ と書けます。しかし実際にこの式を入力すると、画面には意味不明な点群が大量に現れます（下図）。
![上記の式で生成された誤った点群、このときn=5。](/assets/images/QQ_1783412946814.png)
Desmosは多重ループに対して順列組み合わせのロジックを採用しているため、この式が出力する結果は $n^{2}$ 個の要素を含むリストになります。しかし実際に必要なのはn個の要素のリストであるため、案二はpass。

<!-- tab 案三 -->

{% folding title="Desmos代入記号 $\\to$ の使い方入門" class="blue" open=true %}
簡単に言えば：変数を指定したものにすることです。
例： $a=0とし$ 、このとき ${a}\to{1}$ と入力すると、式の左側に矢印が現れます。矢印をクリックすると代入が完了し、この1回の代入はDesmosでは操作（Actions）と呼ばれます。例えばこの例で、この操作を絶えず実行すると、aの値は： ${0}\to{1}\to{1}\to{1}\dots$
同様に： $a=0,A={a}\to{a+1}とし$ 、このときAを実行すると、aの値は： ${0}\to{1}\to{2}\to{3}\dots$ 。
{% endfolding %}

検証の結果、点の $x$ 座標と $y$ 座標をそれぞれリストとして作成すれば、案二の問題を完璧に解決でき、後の作用分析と計算も便利になります。すなわち：
$x_0=[],y_0=[],R_{esetCoordinates}=x_{0}\to{r_{ad}{random(n)-\frac{r_{ad}}{2}}},y_{0}\to{r_{ad}{random(n)-\frac{r_{ad}}{2}}},ここでr_{ad}を星のランダム位置半径とする$
$x_{0}$ 、 $y_{0}$ はどちらも空のリストで、 $R_{esetCoordinates}$ を実行するとn個の乱数に変わります。

{% endtabs %}

以上より、案三が成功 ~~（無感情~~

#### 星の属性（"m"," $v_x$ "," $v_y$ "）

恒星であり光子ではないため、星には常に固有質量があり、各星の質量を保持する集合 $m$ を計算用に作成する必要があります。mは事前に代入しておく必要がありますが、ここでは詳述しません。例えば：

$$
R_{esetMass}=m\to10{random(n)}
$$

$v_x$ と $v_y$ は恒星の運動過程における速度成分を保持するためのもので、空集合として作成すればよく、実行時に自動的にデータが書き込まれます。
