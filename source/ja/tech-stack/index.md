本ページでは、筆者が当サイトを開発&維持する際に使用している主要な技術スタックを、フロントエンド／バックエンドなど多面的にまとめています。

## 一、フロントエンド

### 1.開発環境&エディタ

- **Windows 11 25H2** - ローカル開発用のOS環境
- **Microsoft Visual Studio Code** - メインのコードエディタ
- **Node.js 22.17.1** - JavaScriptランタイム。Hexoおよびそのプラグインの動作基盤
- **NPM** - Node.jsのパッケージマネージャ。プロジェクトの依存関係のインストール&管理に使用
- **Typora（廃止済み）** - かつてMarkdownでの執筆に使用。テーマとの互換性問題により廃止~~実のところ主な理由はこのソフトが有料だから~~
- **DeepSeek** - コードの相談&生成補助
- **GitHub Copilot** - VSCodeに統合されたコード補完&支援AI

### 2.ブログフレームワーク&テーマ

- **Hexo 8.1.2** - Node.jsベースの静的ブログフレームワーク
- **hexo-theme-redefine v2.9.0** - 現在使用しているテーマ
- **EJS** - テーマのテンプレートエンジン
- **Tailwind CSS** - テーマのスタイルフレームワーク
- **Stylus** - CSSプリプロセッサ
- **Font Awesome** - ブログにベクターアイコンを提供するオープンソースのアイコンライブラリ

### 3.コアプラグイン&機能拡張

- **hexo-blog-encrypt** - 記事暗号化プラグイン
- **MathJax** - LaTeX数式のレンダリングエンジン
- **hexo-generator-searchdb** - 検索インデックスデータベースを生成し、フロントエンドと連携してサイト内全文検索を実現
- **hexo-wordcount** - 記事の文字数カウント
- **nodejieba** - 記事推薦に用いる中国語の分かち書きライブラリ
- **aplayer** - 音楽プレイヤー
- **hexo-all-minifier** - リソース圧縮プラグイン。HTML / CSS / JS / 画像などのリソースを圧縮して読み込み速度を最適化
- **Open Graph** - ソーシャルシェアタグの最適化。Facebook、Twitterなどでのリンクプレビュー表示を改善
- **Swup** - リロードなしのページ遷移を実現し、シングルページアプリのような滑らかな閲覧体験を提供

## 二、バックエンド

### 1.デプロイ&ホスティングサービス

- **GitHub** - ソースコードのホスティングサービスを提供
- **Cloudflare** - CDN高速化、セキュリティ保護、ドメイン管理& DNS解決サービスを提供
- **Vercel** - Walineコメントシステム& Qexoブログ管理バックエンドをデプロイするサーバーレスプラットフォーム
- **DigitalPlat** - dpdns.orgの無料サブドメインを提供
- **GitHub Repository** - ソースコードリポジトリ。ブログの全ソース&サイトファイルをホスト
- **GitHub Secrets** - CI/CDフローに必要なAPIキーなどの機密変数を保存
- **GitHub Pages** - 予備のPagesサービス。GitHub Actionsでソースを自動ビルド&公開
- **Cloudflare Pages** - メインサイトの静的ホスティングサービス

### 2.データベース

- **Neon** - Walineのコメントデータを永続化するためのPostgreSQLクラウドデータベース
- **MongoDB** - Qexoのブログ管理データを保存するためのNoSQLクラウドデータベース

### 3. CI/CD 自動化& CDN

- **GitHub Actions** - ビルド、テスト、デプロイ&同期などのタスクを実行する自動化ワークフロー
- **NPM Mirror** - NPMミラー源CDN
