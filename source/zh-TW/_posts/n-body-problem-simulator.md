## 實現

### 可視元素

#### 星體("S")

對於N體問題，首先需要有N個星體，即N個點並用S表示，具體數量應遵循自訂的原則，讓使用者自行調整。
首先應建立變數 $n$ 用以保存使用者輸入的星體數量，同時鍵入 $N_{um}=[1,2,\dots,n]$ 這一列表以備不時之需。此時Desmos會自動補全等差數列。

{% callout type="warning" title="注意變數定義域" icon="fa-solid fa-triangle-exclamation" %}
應注意為所有元素設定定義域（包括範圍、滑桿步長等），避免數學錯誤。
例：

$$
n=15
$$

$$
{2}\le{n}\le{100}~步長:1
$$

~~誰家好人設定-1顆星啊你說對吧~~

註：由於Desmos限制列表長度最大為10000項，故星體數量不得超過100個，否則受力列表項數 $n^2$ 將超過10000項（這一點會在之後提及）。~~設100真的不卡嗎~~
{% endcallout %}

此處的星體作為點陣當然需要設定座標。

**任務一：找到合適的方法表示S**

筆者在編寫此處時想到了以下方案：

{% tabs %}

<!-- tab 方案一 -->

很容易能夠想到令 $S=[(1,2),(3,4),...]$ ，然而為每一項單獨設定畢竟不現實，因而方案一pass。

<!-- tab 方案二 -->

為解決以上問題，我們需要為 $S$ 批次隨機賦值，因此我們引入函數 $random()$ 和列表推導式 $for$ 。~~這玩意在py裡面不是叫迴圈麼~~

{% folding title="Desmos函數random()用法簡介" class="blue" open=true %}
什麼，你問我怎麼用？字面意思，random隨機數。不過有幾點細節要注意：
1.寫 $random()$ 函數必須帶上括號（不管裡面有沒有東西）。
2.在該函數的括號中寫入一個自然數（記為 $x$ ）可以生成一個含有x項不相同的隨機數的列表。
3.該函數生成的隨機數範圍為 $[0,1]$ 且不可調（因為這樣已經圖靈完備了）。如果要調整，參考以下寫法：
$設隨機數的範圍為[a,b]({a,b}\in{\mathbb{R}}),則r=a+random()(b-a)$ 。
{% endfolding %}

{% folding title="Desmos列表推導式for用法簡介" class="blue" open=true %}
利用 $for$ 可以將一個列表中的所有元素遍歷並一一代入計算。例如輸入 $sin(i)~for~i=[1,2,\dots,10]$ 則會輸出：
=`0.0174524064373` `0.0348994967025` `0.0523359562429` `0.0697564737441` `0.0871557427477` `0.104528463268` `0.121869343405` `0.13917310096` `0.15643446504` `0.173648177667`
如果迴圈的變數有2個則可以達到“雙重迴圈”的效果（等同於迴圈中再嵌套一個迴圈。更多變數以此類推）：
$(a,b)\space{for}\space{a}=[1,2,\dots,10],b=[1,2,\dots,10]$
上例將會輸出一個有 ${10}\times{10}=100$ 個點的列表。
{% endfolding %}

根據以上內容便可列出 $S=(a,b)~for~a=random(n),b=random(n)$ 。然而當你真的輸入這個式子你會發現螢幕上有一大堆不明所以的點陣（如下圖）。
![使用上述表達式產生的錯誤點陣，此時n=5。](/assets/images/QQ_1783412946814.png)
由於Desmos對於多重迴圈採用排列組合的邏輯，故該表達式輸出的結果是一個含有 $n^{2}$ 個元素的列表，而我們實際需要的是n個元素的列表，故方案二pass。

<!-- tab 方案三 -->

{% folding title="Desmos賦值符 $\\to$ 用法簡介" class="blue" open=true %}
簡單來說：使變數變成你指定的東西。
例： $令a=0$ ，此時輸入 ${a}\to{1}$ ，表達式左側就會出現一個箭頭。點擊箭頭即可完成賦值，這樣的一次賦值在Desmos中稱為操作（Actions）。如在本例中，如果不斷觸發這個操作，a的值則是： ${0}\to{1}\to{1}\to{1}\dots$
同理可得： $令a=0,A={a}\to{a+1}$ 此時觸發A，a的值就是： ${0}\to{1}\to{2}\to{3}\dots$ 。
{% endfolding %}

經過測試，把點的 $x$ 和 $y$ 座標分別建立一個列表可以完美解決方案二中的問題，同時也方便了後面受力分析與計算，即：
$令x_0=[],y_0=[],R_{esetCoordinates}=x_{0}\to{r_{ad}{random(n)-\frac{r_{ad}}{2}}},y_{0}\to{r_{ad}{random(n)-\frac{r_{ad}}{2}}},其中r_{ad}為星體隨機位置半徑$
$x_{0}$ ， $y_{0}$ 都是空列表，在觸發 $R_{esetCoordinates}$ 之後就會變為n個隨機數。

{% endtabs %}

綜上，方案三成功 ~~（無感情~~

#### 星體屬性("m"," $v_x$ "," $v_y$ ")

作為恆星而非光子，星體總是有內稟質量，因而需要建立集合 $m$ 保存每個星體的質量用於計算。m需提前賦值，此處不做贅述。如：

$$
R_{esetMass}=m\to10{random(n)}
$$

$v_x$ 和 $v_y$ 用以保存恆星運動過程中的速度分量，建立為空集即可，執行時會自動寫入資料。
